## 中文

这个摄影项目记录了上海的人工绿色空间——那些被设计出来、却让人感受到自然的地方。

在自然资源有限的情况下，上海通过人为设计的绿色空间重新定义了"自然"，并将其转化为解决城市环境与社会问题的重要工具。街道两边的行道树、小区里的绿地、滨江的步行空间……这些地方虽然不是自然形成的，但已经融入了上海人的日常生活。

这个项目想探讨的问题是：人工建造的绿色空间，是否也可以算是一种"自然"？

**技术栈**
- React + TypeScript
- Vite
- 自定义 CSS 动画与过渡效果

---

## English

This photography project documents Shanghai's designed green spaces — places that were engineered, yet feel natural.

With limited natural resources, Shanghai has redefined what "nature" means in an urban context, using deliberately designed green spaces as tools to address environmental and social challenges. Tree-lined streets, neighborhood gardens, riverside walkways — these spaces are not naturally formed, yet they have become woven into the rhythms of everyday life.

The central question this project explores: can a designed green space still count as "nature"?

**Built with**
- React + TypeScript
- Vite
- Custom CSS animations and transitions
